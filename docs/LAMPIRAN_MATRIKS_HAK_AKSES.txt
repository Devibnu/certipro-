KETERANGAN:
• Kolom role_id pada tabel USERS adalah Foreign Key ke tabel ROLES
• Setiap user hanya memiliki satu nilai role_id (One-to-One)
• Izin ditentukan oleh relasi role → role_permission → permission
• Tidak ada relasi langsung user → permission
